# Development

For implementation goals, refer to [README.md](./README.md) and follow the guidance provided there.

Keep the following principles in mind:

* Before adding new structs, methods, or functions, consider whether they fit naturally within the intended semantics and design.
* Simplicity is paramount. Do not create unnecessary helper functions or add unnecessary error handling.
* Security matters. Avoid implementing access patterns that depend on secret information.
* Performance matters as well. Implement with efficiency in mind.
